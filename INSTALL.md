## First install

1. On the phone, open the latest APK link above and download it.
2. Open the download. Allow "install from this source" for the browser if Android asks. Install.
3. Open WakiDownload once and allow notifications (progress and "Saved" notifications need it).
4. Share any Twitter / X or TikTok link to WakiDownload.

## Updates

WakiDownload checks GitHub Releases on every cold start and on **Check for updates**. When a newer
build exists it downloads it, verifies the file digest, package name, version code and the release
signing certificate, and then Android shows its own install confirmation. The first time, Android
asks for a one-time "install unknown apps" permission for WakiDownload.

Later APKs always install over the top: every release is signed with the same key.
